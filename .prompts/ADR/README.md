# ADR Prompts

Папка `.prompts/ADR/` хранит промпты для минимального pipeline ревью ADR.

Pipeline двухшаговый:

- `01_review` читает ADR и возвращает только JSON с замечаниями и вопросами;
- `02_improve` читает JSON после `01_review`, вносит правки прямо в ADR-файл и возвращает только JSON-отчет о внесенных изменениях и оставшихся блокерах.

## Files

- [`./01_review.md`](01_review.md)
  Ревью ADR: находит замечания и вопросы.

- [`./02_improve.md`](02_improve.md)
  Улучшает ADR по замечаниям, правит файл по месту и фиксирует результат.
